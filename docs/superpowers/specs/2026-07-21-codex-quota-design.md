# Codex Quota 设计规格

- 日期：2026-07-21
- 状态：已批准
- 仓库：`yushangrong/codex-quota`

## 1. 目标

开发一个可公开分发的 macOS 小工具，在用户直接启动官方 Codex 桌面应用时，将周额度胶囊贴合显示在 Codex 左下角头像右侧。工具从 Codex 本地会话事件读取官方限额数据，不估算 token，不修改 Codex.app，不依赖 Codex++，也不上传对话或额度信息。

首个公开版本通过 GitHub Releases 提供未经过 Apple Developer 公证的 Universal `.dmg`。用户首次运行需右键选择“打开”，并授予辅助功能权限。

## 2. 非目标

- 不修改、重签或替换官方 Codex.app。
- 不注入 JavaScript，不要求调试端口或自定义启动器。
- 不调用私有在线额度接口，不收集 OpenAI 登录凭据。
- 首版不支持 Windows 或 Linux。
- 首版不实现自动更新、遥测、云同步或 Apple Developer 公证。
- 不保证覆盖 Codex 尚未写入本地事件的用量；界面必须明确显示等待或陈旧状态。

## 3. 用户体验

### 3.1 首次启动

1. 用户从 GitHub Releases 下载 Universal `.dmg`，拖入“应用程序”。
2. 因首版未公证，用户首次右键应用并选择“打开”。
3. 应用用简短说明解释辅助功能权限只用于读取 Codex 窗口位置。
4. 用户授权后，应用进入菜单栏并开始监听官方 Codex。
5. 若 Codex 已打开，额度胶囊立即贴合；否则显示菜单栏等待状态。

### 3.2 日常使用

- 用户照常直接启动官方 Codex。
- Codex 位于前台且侧边栏锚点可用时，胶囊显示在头像右侧。
- 移动、缩放、全屏、最小化、切换空间或退出 Codex 时，胶囊跟随、重新贴合或隐藏。
- Codex 不在前台时胶囊隐藏，避免覆盖其他应用。
- 每次 Codex 写入新的限额事件后，胶囊最迟 5 秒内更新。
- 菜单栏提供：当前额度摘要、显示/隐藏胶囊、开机启动、重新授权说明、关于和退出。

### 3.3 胶囊内容与状态

主文案格式：`Codex 63% · 3天后重置`。

- 百分比始终表示剩余额度，计算方式为 `100 - used_percent`，并限制在 `0...100`。
- 优先选取 `limit_id == "codex"` 且窗口为 `10080` 分钟的限额；若字段位于 primary 或 secondary，均应识别。
- 找不到精确 10080 分钟窗口时，不把短窗口冒充周额度；显示等待状态并在菜单栏说明原因。
- 重置倒计时按本地时区生成：大于等于 48 小时显示整数天，24–48 小时显示“1天后”，1–24 小时显示整数小时，小于 1 小时显示整数分钟。
- 正常：剩余大于 30%，绿色。
- 提醒：剩余 10%–30%（含边界），琥珀色。
- 紧急：剩余低于 10%，红色。
- 无数据：`Codex -- · 等待数据`，中性灰色。
- 数据超过 30 分钟未更新时保留最后值，并在菜单栏标记“数据可能已过期”；不把正常的低频额度变化误报为错误。

### 3.4 视觉规格

- 使用系统字体、30pt 高度、胶囊圆角、1px 半透明描边和轻微内高光。
- 外层窗口完全透明、无标题栏、无系统阴影，只绘制胶囊。
- 默认宽度由内容自适应，上限避免越过侧边栏；空间不足时退化为 `63% · 3天`。
- 不显示技术窗口边框，不伪造整块 Codex 界面。
- 跟随 Codex 窗口时允许短暂的一帧延迟；静止后必须像素对齐。

## 4. 技术架构

应用使用 Swift、AppKit 与少量 SwiftUI 构建，最低支持 macOS 13，使用 Universal 二进制覆盖 Apple Silicon 与 Intel。

### 4.1 `QuotaEventReader`

职责：只读取 `~/.codex/sessions` 与 `~/.codex/archived_sessions` 中的 JSONL 限额事件。

- 首次启动扫描最近修改的候选文件。
- 后续每 5 秒检查文件大小和修改时间，只读取新增字节，不重复解析完整历史。
- 只解析 `event_msg` 中的 `payload.rate_limits`，忽略会话正文和其他事件。
- 文件被轮换、归档或截断时重建该文件的读取游标。
- 多个任务同时写入时，以事件时间戳最新的有效周窗口为准。
- 将最后一个有效快照仅保存在本机应用支持目录，内容限于使用比例、窗口长度、重置时间、事件时间和来源文件指纹；不缓存提示词或回复文本。

### 4.2 `QuotaSelector`

职责：从不同版本的限额结构中选择周窗口并生成领域模型。

- 检查 primary 与 secondary。
- 要求 `window_minutes == 10080`。
- 验证百分比、重置时间与事件时间；非法字段不进入 UI。
- 输出剩余百分比、重置日期、数据日期、颜色状态和数据新鲜度。

### 4.3 `CodexWindowTracker`

职责：通过 macOS Accessibility API 定位官方 Codex 的前台主窗口和左下角头像锚点。

- 以官方 bundle identifier 为首选识别方式，进程名仅作兼容回退。
- 使用 AXObserver 监听窗口移动、缩放、最小化与销毁事件。
- 使用低频定时器作为通知遗漏时的回退，不持续高频轮询空闲系统。
- 优先从辅助功能树寻找侧边栏页脚或头像元素的 frame。
- 找不到可靠锚点时使用可配置的窗口相对偏移；若侧边栏明显收起或位置不安全，则隐藏胶囊，而不是覆盖主内容。
- 首版只跟随当前前台的一个 Codex 主窗口。

### 4.4 `OverlayPanelController`

职责：管理透明、非激活式 NSPanel。

- panel 不出现在 Dock 或应用切换器中。
- 不抢占 Codex 键盘焦点。
- Codex 不在前台、窗口最小化、锚点无效或屏幕布局切换期间隐藏。
- 根据窗口跟踪器提供的锚点重新定位，并约束在可见屏幕范围内。
- 胶囊区域可响应悬停，展示已用比例、精确重置时间和数据更新时间；其余透明区域不拦截点击。

### 4.5 `MenuBarController` 与设置

- 菜单栏展示当前剩余额度或等待状态。
- 用户可暂停悬浮层、调整水平/垂直偏移、恢复默认位置。
- 使用 `SMAppService` 管理登录时启动，默认关闭并由用户主动开启。
- 设置保存在 UserDefaults，不包含账号凭据。

## 5. 权限与隐私

- 辅助功能权限仅用于识别 Codex 窗口及 UI 锚点。
- 应用不使用屏幕录制权限，不截屏，不录制键盘输入。
- 应用不监听公网端口，不运行本地 HTTP 服务。
- 首版无网络请求和遥测；GitHub Release 下载由浏览器处理。
- README 与首次启动页明确说明读取的目录、字段和缓存内容。
- 项目名称和说明标注“非 OpenAI 官方项目”，不使用 OpenAI 官方图标冒充官方应用。

## 6. 错误处理

- 未授权辅助功能：菜单栏保持可用，胶囊隐藏，并提供跳转系统设置的说明。
- 未安装或未运行 Codex：显示“等待 Codex”，不弹重复通知。
- 尚无周额度事件：显示等待数据，并提示用户完成一次 Codex 请求。
- JSONL 存在半行写入：保留未完成尾部，等待下次追加后再解析。
- 文件不可读或目录不存在：记录本地诊断日志，采用指数退避，界面不崩溃。
- 重置时间已过但没有新事件：显示“等待刷新”，不自行假定额度已恢复为 100%。
- Codex 更新导致锚点失效：隐藏悬浮层，保留菜单栏数值，并允许用户手动调整偏移。

## 7. 测试与验收

### 7.1 单元测试

- 解析 primary 与 secondary 周窗口。
- 拒绝 5 小时等非周窗口。
- 百分比边界、颜色阈值和倒计时格式。
- 多文件事件按时间戳选最新值。
- 半行、截断、轮换、非法 JSON 和字段缺失。
- 缓存不包含对话正文。

### 7.2 集成测试

- 临时目录模拟持续追加 JSONL，验证 5 秒内更新。
- 模拟 Codex 启动、退出、最小化、移动、缩放和切换前台应用。
- 权限拒绝与随后授权能够恢复。
- 登录启动开关注册与取消注册。

### 7.3 手工视觉验收

- 普通、琥珀、红色、无数据和陈旧数据状态。
- 浅色与深色系统外观；首版胶囊以 Codex 当前暗色侧边栏为基准，若无法可靠识别主题则提供菜单栏外观选择。
- 单屏、多屏、不同缩放比例、全屏与多个空间。
- 侧边栏展开与收起，确保不覆盖主内容。
- 拖动时允许短暂延迟，停止后必须准确贴合。

### 7.4 发布验收

- `swift test` 全部通过。
- Release 构建同时包含 `arm64` 与 `x86_64`。
- `.app` 经过 ad-hoc 签名并能从 `.dmg` 安装。
- 在一台没有开发环境的 Mac 上按 README 完成首次右键打开和授权。
- 卸载说明能移除应用、登录项和本地缓存，不影响 Codex 数据。

## 8. 仓库与发布

- 开源协议：MIT。
- 默认分支：`main`。
- GitHub Actions 在 pull request 上运行测试，在 `v*` 标签上构建 Universal 应用、生成校验和并创建 GitHub Release。
- 首版产物名：`Codex-Quota-v0.1.0-macOS-universal.dmg`。
- Release 页面与 README 明确写出未公证状态、首次打开步骤、权限用途和非官方声明。
- 正式 Apple Developer 签名与公证作为后续可选增强，不阻塞 v0.1.0。

## 9. 完成定义

当以下条件同时满足时，v0.1.0 视为完成：

1. 用户直接打开官方 Codex，无需 Codex++ 或定制启动器。
2. 有有效周额度事件时，胶囊正确显示剩余比例与倒计时。
3. Codex 重启、窗口移动和应用切换后，胶囊能够自动恢复、跟随或隐藏。
4. 工具不修改 Codex.app，不读取对话正文，不向网络发送数据。
5. GitHub Releases 提供可安装的 Universal `.dmg` 和清晰的未签名安装说明。
